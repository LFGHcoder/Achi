# 🎮 Achi — Console Tic Tac Toe Variant

> A simple terminal game inspired by the traditional **Achi** variant (3×3, place then slide pieces).

## How to Play
- Two players take turns placing three pieces each on a 3×3 board.
- After all pieces are placed, players move one piece per turn along valid lines.
- First player to align **three in a row** wins.

## Run Locally
```bash
# Replace <entry.py> with your main python file
python <entry.py>
```
